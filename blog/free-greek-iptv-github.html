Πώς λειτουργούν τα GitHub repos με IPTV playlists

Ένα typical repository με τίτλο κάτι σαν «greek-iptv-m3u» ή «free-iptv-list» περιέχει συνήθως ένα ή περισσότερα αρχεία κειμένου με επέκταση .m3u ή .m3u8. Κάθε γραμμή στο αρχείο περιέχει έναν σύνδεσμο (URL) προς ένα stream, μαζί με μεταδεδομένα όπως το όνομα του καναλιού και το λογότυπο.

Βασική δομή ενός αρχείου M3U

  • #EXTM3U: Η κεφαλίδα που δηλώνει ότι το αρχείο είναι playlist
  • #EXTINF: Πληροφορίες για κάθε κανάλι (όνομα, ομάδα, λογότυπο)
  • URL stream: Ο σύνδεσμος προς τον server που μεταδίδει το κανάλι

Οι σύνδεσμοι αυτοί συνήθως προέρχονται από τρίτους servers, χωρίς καμία εγγύηση σταθερότητας ή νομιμότητας. Πολλά repositories ενημερώνονται αυτόματα μέσω scripts (GitHub Actions) που ελέγχουν αν οι σύνδεσμοι λειτουργούν ακόμα, αλλά ακόμα και έτσι η ποιότητα παραμένει ασταθής.
